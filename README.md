# 📊 Ecommerce Dashboard Analysis

## Overview
This project presents an interactive Power BI dashboard designed to analyze e-commerce performance and provide actionable business insights through KPI tracking and visual analytics.

## Tools Used
- Power BI
- Excel
- Data Cleaning
- Data Visualization
- KPI Reporting

## Project Objectives
- Analyze sales performance
- Monitor key business KPIs
- Identify sales trends and patterns
- Improve data-driven decision making

## Dashboard Features
✔ Interactive filters and slicers  
✔ KPI cards  
✔ Trend analysis  
✔ Sales performance visualization  
✔ Business insights dashboard

## Key Findings

📈 Sales performance changed across months, revealing seasonal purchasing trends

🌍 Customer regions showed differences in sales contribution and overall performance

💰 Profit varied across customer segments, indicating differences in customer value

🛒 Product categories contributed differently to sales and profitability

🏙 Top customer cities generated a significant share of orders and sales activity

✔ Built an interactive Power BI dashboard for e-commerce analysis

✔ Tracked sales, profit, customers, and orders using KPI visuals

✔ Used visual analytics to identify trends and business patterns
